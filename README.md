Below are instructions on how to download Love, which is the framework required to play my game. Please follow the instructions to install Love, then download the executable to play the game!

1. Navigate to love2d.org
2. Select 64-bit installer for Windows or 64-bit zipped for MacOS
3. Run the installer.exe located in the download
4. Select 'Next'
5. Select 'I Agree'
6. Select 'Next'
7. Select 'Install'
8. Select 'Finish'
9. Navigate to https://ditheron.itch.io/scratched or https://github.com/Ditheron/Scratched
10. Download 'Scratched.love'
11. Agree to any security warning
12. Run Scratched.love using the Love framework you just installed (it should work automatically, but if needed, right click the .love file and select Open With > LOVE 11.x)
13. Enjoy!

The object of this game is to get to the end of the third level. You navigate the world in your helicopter, using 'a' or left arrow to move left, 'b' or right arrow to move right, and 'w', space or up arrow to jump.
You must collect all of the stars in the level to advance to the next level. There are 20 stars in total. Do not touch the lava on the ground, nor the skyscrapers that are coming from the ground or the ceiling. 
The skyscrapers coming from the ceiling are due to an 'Inception' style event that is causing this armaggeddon. All stars, obstacles and meteors are dynamically generated through the use of random values.
There is a timer in the upper left corner of the screen when you start the game so you can challenge yourself on completing the game with better times.

If you'd like to view the source code, I've included a zip called sourcecode.zip in the github respository.
